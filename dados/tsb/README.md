# Referencias metodologicas TSB

Esta pasta guarda as tabelas de referencia da Etapa 1. Elas sao exibidas no
dashboard como base metodologica e nao alteram a priorizacao Border Value.

Arquivos esperados:

- `EV1_Relatorio_Final_vf.docx`: relatorio original recebido em 17/07/2026.
- `dim_tsb_cnae5.csv`: CNAEs5 classificados pela TSB, com descricao, setor SCN67 e criterio.
- `dim_scn67_tsb.csv`: setores SCN67, exposicao TSB, grupo de exposicao e leitura tecnica.
- `multiplicadores_scn67.csv`: multiplicadores de producao, renda e emprego. Enquanto a tabela editavel oficial nao chega, os registros setoriais foram transcritos das figuras de decomposicao dos multiplicadores no relatorio.
- `fontes_tsb_robustez.csv`: TSB, duas ou tres fontes e demais referencias usadas.
